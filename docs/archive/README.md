development instructions or an outstanding task list.

- [Architecture review](reviews/ARCHITECTURE_REVIEW.md), [UI review](reviews/FRONTEND_ARCHITECTURE_UI_REVIEW.md), and [handoff](reviews/ARCHITECTURE_IMPLEMENTATION_HANDOFF.md): earlier architecture work.

- [Design experiments](design/design-system.md): the earlier visual specification, prototypes, and tool session metadata. The resume.json paths are preserved as historical tool state.
