# 证据面板四个入口联合设计

## 当前问题

- 诊断作用于整个图谱的采样记录，却与当前论文的外链混排，并占据最强视觉强调。
- 暂存是研究筛选中的主要操作，却位于元数据之后，和外链不在同一操作区。
- 来源按钮保留画布浮层类名；不断加高优先级覆盖，容易在主题和嵌入模式中回退。
- 嵌入模式没有暂存回调，属于功能缺口，不能用样式同步解决。

## 推荐布局

面板标题行：左侧“论文与关系证据”，右侧“诊断候选”。

当前对照版信息区：完整题名 → 作者与年份 → 出处 → 主题标签 → 论文操作行 → 分隔线 → 关系与摘要。

论文操作行：左侧“加入暂存列表”，右侧“OpenAlex ↗”与“DOI ↗”。

诊断入口不随论文切换；其余三个入口严格对应正在显示的论文。

## 尺寸与外观

| 元素 | 设计 |
| --- | --- |
| 面板标题行 | 高约 40px；水平内边距 12px；题名 12px、600 字重；一条底部分隔线 |
| 诊断候选 | 11px；14px 线性搜索图标；28px 命中高度；默认透明，悬停浅底，无阴影 |
| 论文题名 | 14px，1.45 行高，自然换行；作者年份 11px 次级色 |
| 出处 | 独立文字行；期刊名稍强调，卷期与页码次级显示；缺失字段不留空占位 |
| 主题标签 | 不显示“主题”字段名；标签组保留无障碍名称；10px 文字、22px 高、轻灰主题底色；最多展示 3 个，余项以“+N”展开 |
| 暂存 | 30px 高；12px 文本；14px 书签图标；5px 圆角；细强调色边框与轻微底色，无阴影 |
| 两个外链 | 11px；文本后 12px 外链图标；30px 命中高度；无默认边框和底色，悬停才有浅底 |
| 对齐 | 图标与文字垂直居中；三个论文操作同一基线；段落与操作区共同左边界 |
| 主题 | 所有颜色来自 Obsidian 主题变量，深色主题同样保持层级；不写死蓝色、白色或金色 |

默认 320px 侧栏中，296px 内容宽度应完整显示一行三项。内容宽度不足时，把两个外链作为整体移至暂存按钮下一行；不截断文字、不拆开外链组。以实际元素尺寸决定断点，不缩小字号硬塞。

## 状态

- 未选论文：只显示面板级诊断；没有可误点的暂存和来源链接。
- 非种子论文：显示暂存和有效外链；暂存后显示“已暂存”，保持控件宽度，再次点击可移除。
- 保存中：按钮短暂禁用；保存失败保留原状态并显示错误，不能先显示保存成功。
- 种子论文：沿用现有不暂存种子的语义，只显示其有效来源链接。
- 无 DOI：不伪造入口；移除该链接，OpenAlex 仍与暂存所在区域对齐。
- 诊断视图：隐藏当前论文操作，提供“返回论文”，保留用户原来的论文选择与上下文。
- 窄面板、深浅主题、已暂存和未暂存都使用同一套组件规则。

## 落地边界与验收

共享面板标题和论文操作组件，图谱与嵌入调用同一实现。用面板专用类名取代画布 `cpo-action-link` 与通用 `cpo-text-btn`，删除旧覆盖规则。暂存读写沿用现有项目数据结构，嵌入宿主补齐保存回调。

验收必须查看真实页面截图，覆盖 260/320/480px 面板、长题名、浅色/深色主题、种子/非种子、无 DOI、暂存切换及保存失败。浏览器无障碍树或源码检查不等于视觉验收。

主题紧跟出处后再接操作行，是便于比较的次序版本；生产实现应以最终选定稿为准。
